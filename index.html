What is this?

AgentVerse is a modern chat application inspired by the classic Microsoft Agent software. Built with Node.js and Socket.IO, it lets you chat using Microsoft's iconic animated assistant characters with authentic SAPI 4 voices by Lernout & Hauspie.

The project originally began as BonziWORLD Revived (BWR), but has since grown into its own independent project with many new features, characters, and improvements. Today, AgentVerse is developed separately and is not affiliated with BonziWORLD or any BonziWORLD-related communities.

Features

A real-time chat room where the characters are the star.

  • Animated charactersYou'll login as your Steam username and the server picks an agent character for you. Certain iconic characters such as BonziBuddy, Clippy, and Kinito are available.
  • Authentic SAPI 4 voicesMessages are spoken aloud with the classic Lernout & Hauspie voices. SAPI 4 text-to-speech is generated with TETYYS/SAPI4.
  • Real-time roomsPowered by Socket.IO, so everyone in the room sees and hears the same thing.
  • Always growingStarted as BonziWORLD Revived, now its own project with new features, characters and improvements.
  • Built on Electron for WindowsDownload the standalone desktop app for a native Windows experience, complete with custom window controls and seamless integration.

Questions

What is AgentVerse?

AgentVerse is a modern chat application powered by Socket.IO and Node.js, also inspired by the classic Microsoft Agent software. You chat as an animated assistant character such as BonziBuddy, or Clippy, with authentic SAPI 4 voices by Lernout & Hauspie.

Is this the same app as BonziWORLD?

No. The project began as BonziWORLD Revived (BWR) but has grown into its own independent project. AgentVerse is developed separately and is not affiliated with BonziWORLD or any BonziWORLD-related communities.

Do I need to install anything?

Yup. You can download the Electron app for your system.

Is it affiliated with Microsoft?

No. AgentVerse is an independent fan project inspired by Microsoft Agent. Microsoft and Microsoft Agent are trademarks of Microsoft Corporation.

We use TETYYS's SAPI4 for SAPI4 TTS generation.
